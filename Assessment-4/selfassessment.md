1. <section> vs <div>
<section> is a semantic tag used for accessibility and readability. It specifies that related content is stored in it to make HTML easier to read and understand. Unlike <section>, a div tag is for general purpose and doesn't indicate any particular information; it is mainly used for styling and scripting purposes.

2. <article> vs <section>
<article> is for self-contained content that makes complete sense on its own and could be syndicated or redistributed independently, like a blog post. <section> is used to group related content together under a shared topic or heading within a page or article.


3. Linking <label> to <input>
Linking a label to an input is an essential task that tells the browser a specific label is associated with a specific input (for example, linking an "Enter your name" label to its text box). This improves accessibility and readability for people with disabilities using screen readers, and it also makes the label text clickable to focus the input.

4. <b> vs <strong>
The b tag is a bold tag that makes text bold to simply bring visual attention to those words. The strong tag shows high importance, seriousness, or urgency to that content from a semantic point of view.

5. srcset and sizes
srcset is a list of image source files paired with their actual pixel widths (like image-small.jpg 400w, image-large.jpg 1200w), giving the browser a menu of available sizes to choose from instead of forcing everyone to download one massive image. sizes tells the browser how wide that image will actually be displayed on the screen across different layout breakpoints.

6. defer attribute on <script>
The defer attribute tells the browser to download the script file in the background while it keeps building and parsing the HTML page.
